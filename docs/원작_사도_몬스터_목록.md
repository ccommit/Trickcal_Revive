## 방법론과 한계

- **성격/성급/역할군/배치위치는 tr.triple-lab.com에서 실제로 가져왔다.** namu.wiki 등 위키 계열은 이 세션 내내 WebFetch가 403으로 막혔고 WebSearch도 인포박스 표를 안정적으로 못 읽어와서(앨리스 1명 테스트에서도 절반만 나옴), 사용자가 알려준 tr.triple-lab.com을 대신 사용했다. 이 사이트는 SPA라 정적 HTML만으로는 빈 화면이라, 헤드리스 크롬(`--dump-dom`, 뷰포트를 강제로 키워 가상 스크롤 리스트 104개 항목을 한 번에 렌더링)으로 실제 렌더링된 DOM에서 다음을 추출했다:
  - 성격: `<img class="... bg-personality-{Cool|Gloomy|Jolly|Mad|Naive} ...">` (같은 사이트 `/board` 페이지에서 이름당 1개 값으로 충돌 없이 재검증됨)
  - 역할군: `/icons/Common_UnitClass_000{1|2|3}.png` (1=딜러, 2=탱커, 3=서포터 — 사용자가 직접 확인해 알려준 값)
  - 배치위치: `/icons/Common_Position{Front|Middle|Back|Free}.png` → 전열/중열/후열/모든열
  - 성급: `HeroGrade_*.png` 파일명이 아니라 `flex flex-row justify-center -mt-1.5 -mb-2 z-10` 컨테이너 안에 들어있는 `<img>` 개수. 사용자가 비비(3개→3성), 페스타(2개→2성)로 직접 확인해줌. 104명 분포: 1성 12명 / 2성 19명 / 3성 73명. (처음에 파일명 코드값을 성급으로 잘못 해석해 3성/엘다인으로 오기했던 버전을 이 값으로 교정함)
- **tr.triple-lab.com에서 못 찾은 나머지(약 39명)는 여전히 빈칸이다.** 이 사이트의 캐릭터 번역 사전에도 없었던 이름들이라(`Uros`, `Miro`, `AliceSister` 등), 현재 라이브 서비스 로스터에 없는 구버전 내부명이거나 NPC/몬스터 전용 리소스일 가능성이 있다.
- **몬스터 역할군만 예외적으로 파일명 근거로 일부 채움.** 몬스터 파일명 자체에 `Dealer`/`Tanker`/`Supporter`/`Wizard`가 그대로 들어있는 경우(예: `ElfCursedDollTanker`)는 파일명 자체가 근거라 채워 넣었다. 표에 "(파일명 근거)"로 표시. 몬스터는 tr.triple-lab.com에 없어(사도 전용 사이트) 성격/성급/배치는 여전히 빈칸이다.
- **사도 이름 정리 규칙**: `herohead` 폴더의 `이름+SkinN.png`는 같은 사도의 코스메틱 스킨이라 하나로 합쳤다. `Yester`/`Rehab`/`Awaken`/`MK2`/`Chaos`/`Sane`/`Royale`/`Graduate`/`Renewa`/`Twisted`/`Swim`/`Cool`/`Mayor`/`Hero`/`PureShine`처럼 실제로 별도 개체로 취급될 수 있는 접미사는 스킨이 아니라 그대로 별도 행으로 남겨뒀다(정확히 스킨인지 별도 사도인지는 확인 필요).
- **몬스터 목록에서 `Monster<사도이름>` 형태(예: `MonsterAlice`, `MonsterJoanne`)는 제외했다.** 이건 원작에서 사도를 적으로 재활용하는 콘텐츠(모의전 등)용 리스킨이라, 위 사도 목록과 중복이고 별도 몬스터 디자인이 아니기 때문이다.
- **NPC 추정 항목**은 비고에 "NPC/비플레이어블 추정, 확인 필요"로 표시했다(`NPC_PaperPlayer`, `EliasCitizen`, `RenewaNPC`, `Noone`).
