## 4. 파티편성

- 우측 3열 스크롤 로스터. 진형 전열·중열·후열 3×3, 최대 6명.
- 카드 선택→해당 열 y=2→1→3 자동배치. 모든열 사도는 전열→중열→후열.
- 자동편성: 전열(3,2)(3,1)(3,3)→중열(2,2)(2,1)(2,3)→후열(1,2)(1,1)(1,3). 빈자리 없거나 6명이면 미배치.
- 배치카드 재탭 = 제외(토글).
- 배치 사도 = 전투용 Spine 대기애니(이름 미확인 시 setup pose + 미확인 표기), 화면당 최대 6 Spine. 로스터카드 = 정적 아이콘.
- 필터(최소)·전투력 정렬·일괄해제·초기화·되돌리기 = 실동작.
- 대여·빠른전투·자동전투 = 표시하되 비활성("범위 아님" 안내).
- 드래그앤드롭 = 원본 근거 발견 시에만.
- 출발 = 검증→요청→컨텍스트 조립까지만, 화면이동 없음, 결과 로그. 원본 `WindowDeckEdit` 프리팹 대조.
