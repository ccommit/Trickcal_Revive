# 11. 사도 스킬 설계서

> 작성 기준일: 2026-08-04
> 문서 성격: `사도_스킬_목록.md`가 조사한 30명의 원작 스킬(타겟·효과·계수)을 `04_전투_설계서.md`가 확정한 구조(타겟팅 Strategy 12종, 버프/디버프 34종 카탈로그, `combat_master` 스키마)에 맞춰 데이터로 구체화한다.
> 근거: `사도_스킬_목록.md`(전체), `04_전투_설계서.md` §4·§5, `DB_설계서.md` §4.2, `10_사도스탯성장_설계서.md`
> 수치 성격: 계수(%)는 원작 실측값(그릴링 결정) — Lv1/Lv10 두 값만 원작에 있고 중간 레벨은 없음. 나머지는 이번에 구조화한 설계값.

## 0. 표기 규칙

- **타겟 전략 ID**: `04_전투_설계서.md` §5의 12종(`CurrentTarget`/`Nearest`/`Farthest`/`LowestHpRatio`/`HighestAttack`/`AreaAroundTarget`/`RandomTargets`/`Self`/`WholeParty`/`AroundSelf`) + 조합기 `ColumnFilter`(열 필터)/`PreferStatus`(상태 우선). 괄호로 대상 진영·인원·열을 보충한다. 예: `LowestHpRatio(ally,2)` = 아군 중 HP비율 최저 2명.
- **버프/디버프 ID**: `04_전투_설계서.md` §4.8의 34종 매핑표 이름을 코드로 옮긴 것. §1에 전체 카탈로그.
- **계수 보간**: 원작은 Lv1/Lv10 두 값만 있다. 중간 레벨(2~9)은 프로젝트 전반의 선형 성장 철학(`레벨디자인_설계서.md` §2.1)과 통일해 **선형 보간**한다.
  ```text
  coefficient(level) = coefficient_lv1 + (coefficient_lv10 - coefficient_lv1) × (level - 1) / 9
  ```
- **`damage_source`**: 명시 없으면 `attack`(공격력 비례). `max_hp`로 별도 표기된 것만 예외(리코타 액티브 조건부).

## 4. 조건부 계수(`combat_master.skills.conditions[]`) 목록

```text
conditions[] 항목 구조:
{
  condition_type: string,       // 조건 종류 (아래 목록)
  target: "self"|"target",      // 조건을 판정할 대상
  effect: string,                // 조건 충족 시 벌어지는 일
  coefficient_alt_lv1: number|null,
  coefficient_alt_lv10: number|null,
  damage_source_alt: string|null
}
```
