이 문서는 그동안의 그릴링 세션에서 원본 기획서를 벗어나 새로 정하거나 바꾼 내용을 포함해, 현재 프로토타입이 실제로 동작하는 방식 전체를 한 문서에 요약한다. 데이터 스키마의 세부 필드는 DB_설계서.md, 레벨/보상 수식은 레벨디자인_설계서.md를 따로 참고한다.

## 1. 프로젝트 개요

- 1인 개발 포트폴리오용, 트릭컬 리바이브풍 모작.
- 단일 HTML 파일(`docs/트릭컬_기획_프로토타입.html`)로 전체 화면과 로직을 프로토타이핑한다. 외부 이미지·라이브러리 없이 모든 비주얼을 CSS 도형·이모지·그라디언트로 표현한다.
- 16:9 고정 비율(`#game`) 안에서만 동작. 수치·룰은 원작과 무관하게 이 프로젝트 자체 설계를 따른다.

## 2. 계정 시스템

- 아이디/비밀번호 로그인 방식. 로컬스토리지의 계정 맵(하나의 키에 `{아이디: {아이디, 비밀번호, 세이브}}` 형태로 여러 계정 저장) 위에서 동작해 기기 하나로 여러 계정을 오갈 수 있다.
- 처음 보는 아이디로 로그인을 시도하면 그 아이디+비밀번호 조합으로 신규 가입 처리하고, 닉네임 입력 팝업을 띄운 뒤 확인하면 계정을 생성하고 바로 로그인한다.
- 이미 존재하는 아이디는 비밀번호가 일치해야 로그인되고, 틀리면 안내 토스트만 뜬다. 아이디는 맵의 키이므로 자동으로 중복될 수 없다.
- 로그인에 성공하면 별도 세션(마지막 로그인 아이디)을 저장한다. 페이지를 새로고침해도 세션이 남아 있으면 Login 화면을 거치지 않고 바로 로비로 이어진다. Login 화면은 로그아웃한 뒤에만 다시 보인다.
- 로비 메뉴 > 설정 팝업에 계정 관련 기능을 모아둔다.
  - 로그아웃: 세션만 해제, 계정 데이터는 그대로 남는다.
  - 계정 초기화: 확인창을 거친 뒤 아이디·비밀번호·세이브 데이터를 전부 삭제한다(이전의 "저장 초기화"와 동일한 파괴적 동작이며, Login 화면이 아닌 여기로 옮겨졌다).
- 비밀번호는 프로토타입 특성상 평문으로 저장한다. 백엔드 없는 단일 HTML 클라이언트라 실질적인 보안 경계가 없어, 해시 처리는 의미 없는 연출이라 생략했다.

## 3. 전체 화면 흐름

```
Login → Lobby ─┬─ StageSelect → PartySetup → Loading → Battle → ResultOverlay
               ├─ Gacha
               ├─ Roster → CharacterDetail
               └─ (메뉴) Backpack / 설정
```

| 화면 | 진입 방법 | 주요 동작 |
|---|---|---|
| Login | 세션 없이 앱 시작, 또는 로그아웃 | 아이디/비밀번호 로그인, 신규 아이디는 닉네임 등록 후 가입 |
| Lobby | 로그인 성공 | 재화·프로필 표시, 모험/모집/사도 진입, 메뉴(배낭/설정) |
| StageSelect | 로비 "모험" | 챕터·스테이지 목록, 잠금/클리어/별 상태 |
| PartySetup | 스테이지 선택 | 파티 3×3 배치, 자동편성/초기화 |
| Battle | 파티 편성 후 출발 | 5웨이브 자동전투 (§4) |
| ResultOverlay | 전투 종료 | 승리/패배 보상, 기여도 표시 |
| Gacha | 로비 "모집" | 1/10회 모집 + 카드 공개 애니메이션 + 결과 그리드 (§5) |
| Roster | 로비 "사도" | 보유/미보유 12명 목록, 정렬 |
| CharacterDetail | 로스터 카드 클릭(보유만) | 정보/레벨업/스킬/승급 탭 |
| Backpack | 로비 메뉴 "배낭" | 소지 스펠 카드 등 인벤토리 |

## 4. 전투 시스템

### 4.1 웨이브 구성

- 5웨이브 고정. 각 웨이브는 준비 단계 → 전투 단계 순으로 진행된다.
- 준비 단계(40초): 상단 배속 버튼(x1/x2/x3)의 영향을 받지 않고 항상 실제 1배 속도로 흐른다. 코인으로 카드(사도 승급/장비/스펠)를 구매한다.
- 전투 단계(80초): 배속 버튼이 그대로 적용되어 x3이면 약 3배 빠르게 진행된다.

### 4.2 사거리·이동 기반 자동전투

- 모든 유닛은 사거리(`range`)를 갖는다. 타겟까지 거리가 사거리보다 멀면 타겟 방향으로 이동하고, 사거리 안에 들어오면 멈춰서 자신의 공격속도(`interval`, 배속 적용)에 맞춰 자동 공격한다.
- 이동 속도는 전체 유닛 공통 고정값을 사용한다(캐릭터별 개별 이동속도는 이번 범위 밖). 위치 갱신은 100ms 간격 tick으로 촘촘히 돌려 이동이 매끄럽게 보이도록 한다.
- 타겟이 없으면(적 전멸 등) 원래 대형 위치로 복귀한다.
- 몬스터는 처치되는 즉시 화면에서 사라진다(잔류 표시 없음).
- 웨이브를 클리어한 순간, 그리고 전투가 완전히 종료(승리/패배)된 순간에 생존한 사도는 강제로 원래 대형 위치로 스냅한다.

### 4.3 액티브 스킬(고학년 스킬)

- 4학년 이상부터 사용 가능. 전투 화면 하단에 현재 소환된 사도 수만큼 아이콘이 표시되며, 배치 순서는 장비 장착 팝업과 동일하게 후열→중열→전열 순, 각 열 내부는 y=3, y=1, y=2 순서를 따른다.
- 4학년 미만인 사도의 아이콘은 세로 방향으로 절반 정도가 가려진 잠금 형태로 표시된다.
- 아이콘을 클릭하면 쿨타임 10초가 시작된다(배속의 영향을 받아 x3이면 약 3.3초 만에 해제). 쿨타임 중에는 회색 마스크가 12시 방향에서 시계방향으로 걷히며, 남은 초를 올림한 숫자를 아이콘 위에 표시한다. 쿨타임 중 재클릭은 무반응이다.
- 이번 세션 기준 클릭은 쿨타임 연출까지만 담당하며, 실제 피해·효과 발동 로직은 아직 붙어 있지 않다. 이는 후속 "전투 시스템 개선" 세션의 범위다.
- 각 아이콘 아래에는 해당 사도의 체력(위, 초록) / SP(아래, 파랑) 바가 표시된다.

### 4.4 AUTO 모드

- 로비/전투 상단 AUTO 버튼으로 켜고 끌 수 있다. 계정을 새로 만들면 저장된 배틀 옵션값을 그대로 따르며(과거처럼 매 전투가 무조건 켜진 채 시작하지 않는다), 이후 값은 계정별로 저장되어 다음 전투에도 유지된다.
- 켜져 있을 때 동작:
  - 준비 단계: 2초 간격으로 카드 자동 구매를 시도한다. 구매 가능한 카드가 여러 장이면 그중 무작위로 하나를 사고, 현재 뜬 3장이 전부 보유 코인보다 비싸면 즉시 전투 단계로 넘어간다.
  - 장비 카드를 자동 구매한 경우: 구매 직후 1초 뒤에 장착 화면이 열리고, 다시 1초 뒤에 장비 여유가 있는 사도 중 무작위 1명에게 장착한다. 팝업이 닫힌 뒤 2초가 지나면 다음 자동 구매 사이클이 이어진다.
  - 전투 단계: 4학년 이상이고 쿨타임이 없는 소환된 사도는 매 tick마다 즉시 액티브 스킬을 자동으로 사용(쿨타임 시작)한다.
- AUTO가 켜져 있는 동안에는 카드 구매 버튼과 액티브 스킬 아이콘의 수동 클릭이 막히고 "자동 진행 중입니다" 토스트가 뜬다.

## 5. 모집(가챠) 시스템

- 배너 1종만 동작. 확률은 1성 60% / 2성 30% / 3성 10%이며, 10연 모집 시 2성 이상 1개를 확정 지급한다.
- 뽑기 실행 시 결과를 곧바로 보여주지 않고, 뽑은 순서대로 카드 공개 애니메이션을 먼저 진행한다.
  - 카드마다 전체화면 레이어로 표시되며, 배경은 해당 사도 성격 색으로 대각선 그라디언트를 이룬다(광기=빨강, 순수=초록 등 기존 성격 색상표를 그대로 사용).
  - 화면 중앙에 큰 캐릭터 초상화, 좌측에는 뽑힌 사도의 고유 초기 성급(보유 중인 성급이 더 높아도 항상 초기 성급 개수만) 과 이름만 표시한다. 한마디·TMI 같은 부가 텍스트는 이번 화면에서는 생략한다.
  - 우상단에는 반투명 스킵 버튼이 있고, 그 아래 해당 사도의 성격 아이콘과 성격 이름이 표시된다. 스킵을 누르면 남은 카드를 전부 건너뛰고 바로 결과 그리드로 이동한다.
  - 중복 사도인 경우 우하단에 항상 초록색 "중복 사도 전환!" 문구와 사도조각 아이콘이 함께 뜬다. 신규 사도인 경우 성급 위에 성격 색을 따르는 NEW 배지가 붙는다.
  - 카드는 클릭/탭해야 다음 카드로 넘어간다(자동 진행 없음).
- 카드를 전부 확인(또는 스킵)하면 결과 그리드 화면으로 전환된다. 뽑은 수만큼 5열 그리드로 배치되며(10연이면 5×2), 창은 화면 전체를 채운다.
  - 화면을 유지하는 동안 중복으로 얻은 칸은 2초간 캐릭터 초상화를 보여주고, 2초에 걸쳐 사도조각 아이콘으로 부드럽게 크로스페이드했다가 다시 2초 뒤 초상화로 돌아오는 것을 반복한다.
  - 신규로 얻은 칸은 좌상단에 NEW 배지가 붙은 초상화로 고정되며, 조각 아이콘으로는 전환되지 않는다.
  - "확인" 버튼을 누르면 모집 화면으로 돌아간다. "한 번 더 뽑기" 버튼은 참고 화면에는 있으나 이번 세션 구현 범위 밖으로 남겨두었다.

## 6. 사도(캐릭터) 시스템

- 총 12명. 이 중 6명(앨리스, 란, 조안, 우로스, 미로, 아멜리아)은 계정을 새로 만들 때부터 보유한 "스타터"다. 나머지 6명(로이, 넬, 피오, 달리아, 유키, 코비)은 처음엔 미보유 상태이며 모집으로만 얻을 수 있다.
- 로스터 화면은 보유·미보유 사도를 함께 나열하되, 미보유 사도는 실루엣으로 표시되고 클릭하면 "미보유 사도입니다. 모집으로 획득하세요" 안내만 뜬다(상세 화면 진입 불가).
- 각 사도는 성격(광기/순수/냉정/우울/활발) × 역할(딜러/탱커/서포터/기타) 조합과 배치열(전열/중열/후열/모든열), 초기 성급(1~3), 사거리·공격속도 등 전투 스탯을 가진다.
- 스킬은 3종류다: 일반 공격(항상 사용), SP 스킬(SP가 가득 차면 자동 발동, 학년 무관), 액티브 스킬(4학년 이상, §4.3 참고).
- 장비는 사도당 최대 3슬롯이며, 준비 단계의 장비 카드 구매로 장착한다.

## 7. 성장·경제 (요약)

상세 수식은 `docs/레벨디자인_설계서.md`를 따른다. 이번 세션에서 이 수식들 자체는 바뀌지 않았다.

- 레벨 성장(HP/공격/방어만 적용): `stat(level) = base_stat × (1 + 0.03 × (level-1))`
- 스테이지 권장 레벨: `min(99, (챕터-1)×10 + 스테이지번호)`
- 웨이브 마리 수: 2 / 3 / 3 / 4 / 4 고정, 정예·보스는 챕터 구간별 규칙
- 스태미나: 전 스테이지 공통 6
- 보상: 골드 `100 × 권장레벨`, 경험치 `50 × 권장레벨`, 첫 클리어 ×5 보너스
