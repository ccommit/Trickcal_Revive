로비 → 모험 → 침략 세부 기획서

목표는 로비의 모험 버튼을 눌러 콘텐츠 허브로 이동하고, 그 안에서 침략을 선택해 다음 세부 기획서인 스테이지 선택 화면으로 연결되는 지점을 고정하는 것입니다.

전체 화면 흐름

  1. 로비 연결 화면 표시
  2. 모험 버튼 클릭
  3. 모험 화면 페이드 인
  4. 콘텐츠 버튼 표시
  5. 침략 클릭
  6. localStorage에 선택 상태 저장
  7. trickcal:stage-select-requested 이벤트 발행
  8. 스테이지 선택 연결 예정 안내 표시

이번 HTML의 구현 범위

  • 1280×720 기준 16:9 가로형 모바일 UI
  • 로비 연결 화면과 모험 허브 화면 분리
  • 침략만 다음 단계 연결 대상으로 처리
  • 나머지 콘텐츠는 추후 구현 예정 팝업 처리
  • 기획 데이터와 화면 상태를 localStorage에 저장
