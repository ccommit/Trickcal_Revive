요약

1인 개발 포트폴리오용 트릭컬 리바이브풍 모작 프로토타입. 아이디/비밀번호 로그인(계정별 세션 유지) → 로비에서 모험/모집/사도 진입. 전투는 5웨이브 고정, 준비(40초, 배속 무관) → 전투(80초, 배속 적용) 순으로 진행하며, 사도는 사거리 밖이면 이동하고 사거리 안에서만 공격속도에 맞춰 자동 공격한다. 4학년 이상 액티브 스킬은 하단 아이콘 클릭 시 10초 쿨타임 연출을 갖는다(실제 발동 로직은 후속 세션 범위). AUTO 모드는 준비단계 자동 카드구매/장착과 전투단계 액티브스킬 자동 사용까지 담당한다. 사도는 스타터 6명 + 모집 전용 6명, 총 12명이며 모집은 카드 공개 애니메이션과 결과 그리드 연출을 거친다.
